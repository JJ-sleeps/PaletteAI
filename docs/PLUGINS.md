# Building a PaletteAI plugin

A plugin adds **result panels** (and optionally **API routes**) to PaletteAI
without changing any core file. Panels are rendered by PaletteAI itself, inside
its own page, so a plugin looks like part of the app and inherits its themes
and accessibility behaviour.

There are two ways to plug in. Both use the same `Panel` format.

| | Local plugin | Webhook plugin |
|---|---|---|
| What it is | a folder in `plugins/` | any HTTP service (any language) |
| Runs | inside the PaletteAI process | as its own process |
| Can add API routes | yes, under `/api/v1/ext/<name>/` | it has its own server |
| Install | drop the folder in, restart PaletteAI | `POST /api/v1/plugins` or the Developers tab |
| Example | `plugins/tints_and_shades/plugin.py` | `examples/webhook_plugin.py` |

The full REST reference is generated by the running app: **`/docs`** (Swagger UI),
**`/redoc`**, and **`/openapi.json`** (OpenAPI 3.1). The `PanelRequest` webhook
and the `Panel` schema are part of that document.

## Slots: where a panel appears

| Slot | Shown | `palette` in the request |
|---|---|---|
| `palette.result` | under every extracted / opened palette | the full palette object |
| `library` | at the bottom of the Library & ranking tab | `null` |

## The request a plugin receives

```json
{
  "event": "panel.requested",
  "slot": "palette.result",
  "user": "guest",
  "api_base": "http://127.0.0.1:8000/api/v1",
  "palette": {
    "id": 3,
    "k": 5,
    "colors": [
      {"hex": "#1C3454", "rgb": [28, 52, 84], "lab": [21.3, 1.1, -22.6], "share": 0.33,
       "percent": 33.2, "name": "dark blue", "text_color": "#FFFFFF",
       "cvd": {"protanopia": "#17335A", "deuteranopia": "#1E3454", "tritanopia": "#1A3A3F"}}
    ],
    "accessibility": {"pairs": [{"a_hex": "#1C3454", "b_hex": "#F5EFE0", "ratio": 11.4,
                                 "aa_normal_text": true, "aa_large_text": true, "aaa_normal_text": true}],
                      "total_pairs": 10, "aa_normal_pairs": 4},
    "features": {"mean_lightness": 0.61, "mean_chroma": 0.42},
    "image": {"id": 3, "filename": "poster.png", "width": 480, "height": 320}
  }
}
```

Use `api_base` for call-backs, e.g. `GET {api_base}/ranking?user=guest`,
`POST {api_base}/contrast`, `POST {api_base}/harmony`.

## The `Panel` a plugin returns

```json
{
  "title": "Best text pairs",
  "blocks": [
    {"type": "status", "level": "ok", "text": "4 of 5 pairs pass WCAG AA."},
    {"type": "text", "text": "Any explanation, up to 2000 characters."},
    {"type": "stat", "label": "Pairs checked", "value": "10"},
    {"type": "swatches", "label": "Suggested", "colors": [{"hex": "#86B6EF", "label": "tint"}]},
    {"type": "table", "caption": "Top pairs", "columns": ["Text", "Background", "Contrast"],
     "rows": [["#1C3454", "#F5EFE0", "11.4:1"]]},
    {"type": "bars", "caption": "Contrast per pair", "unit": ":1",
     "items": [{"label": "#1C3454 on #F5EFE0", "value": 11.4, "hex": null}]}
  ]
}
```

Rules: at most 20 blocks; `status.level` is `info`, `ok`, `warn` or `fail`
(shown with an icon and a word, never colour alone); tables need a caption;
blocks are plain data, so HTML and scripts are never executed. A panel that
fails validation, raises, or takes longer than **3 seconds** is replaced by a
short "unavailable" notice. The rest of the page keeps working.

## Option A: local plugin (Python)

Create `plugins/my_plugin/plugin.py`:

```python
from fastapi import APIRouter

def register(host):
    host.describe("One line shown on the Developers tab.")

    def panel(context):                      # context = the request shown above, as a dict
        palette = context["palette"]
        darkest = min(palette["colors"], key=lambda c: c["lab"][0])
        report = host.api.contrast("#FFFFFF", darkest["hex"])      # core colour tools, no HTTP
        return {"title": "Darkest colour", "blocks": [
            {"type": "swatches", "colors": [{"hex": darkest["hex"], "label": darkest["name"]}]},
            {"type": "stat", "label": "White text on it", "value": f"{report['ratio']}:1"},
        ]}

    host.add_panel("palette.result", panel)

    router = APIRouter()                     # optional: your own endpoints

    @router.get("/hello")
    def hello():
        return {"palettes": len(host.api.list_palettes())}

    host.add_router(router)                  # -> GET /api/v1/ext/my_plugin/hello, listed in /docs
```

Restart PaletteAI. `host.api` offers `get_palette(id, user)`, `list_palettes(user, saved_only)`,
`ranking(user, scope)`, `contrast(fg, bg)`, `harmonies(hex)`, `simulate_cvd(hex, kind)`
and `describe(hex)`.

## Option B: webhook plugin (any language)

1. Run a service with one endpoint that accepts the request above and returns a `Panel`.
2. Register it:

```bash
curl -X POST http://127.0.0.1:8000/api/v1/plugins -H "Content-Type: application/json" -d "{\"name\": \"Best text pairs\", \"hook_url\": \"http://127.0.0.1:8001/hook\", \"slots\": [\"palette.result\"]}"
```

Unregister with `DELETE /api/v1/plugins/{id}`; list with `GET /api/v1/plugins`.
The complete working example is `examples/webhook_plugin.py`.

## Useful endpoints for plugin authors

| Method and path | Purpose |
|---|---|
| `POST /api/v1/images` (multipart `file`, optional `k`) | upload an image, extract its palette |
| `GET /api/v1/palettes/{id}?user=` | one palette with coverage, contrast and CVD data |
| `GET /api/v1/palettes?user=&saved=true` | a user's library |
| `PUT /api/v1/palettes/{id}/feedback` `{user, value}` | like / dislike |
| `GET /api/v1/ranking?user=&scope=saved` | personalised ranking and the model behind it |
| `POST /api/v1/contrast` `{foreground, background}` | WCAG contrast check |
| `POST /api/v1/harmony` `{color}` | harmony schemes |
| `POST /api/v1/cvd/simulate` `{colors, types}` | colour-vision simulation |
| `GET /api/v1/panels?slot=&palette_id=&user=` | what the web app calls to collect plugin panels |

Errors always look like `{"detail": {"code": "invalid_image", "message": "..."}}`.
